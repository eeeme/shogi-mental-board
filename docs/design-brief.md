# デザインブリーフ — 将棋 脳内盤トレーニングアプリ

Claude Design で各画面をデザインするための情報。方向性の叩き台であり、最終判断はデザイン時に。

## 1. このプロダクトは何か

盤を見ずに座標や手順を扱う力（脳内盤）を鍛えるトレーニングアプリ。将棋を「遊ぶ」アプリではなく、**上達のために毎日短時間まわす筋トレ器具**に近い。

## 2. 誰のためか（当面は自分）

- 将棋アマチュア初段前後、上達に本気の指し手。
- 使う場面: 通勤中・スキマ時間。片手・短時間。音声中心で「画面を見ないで使う」瞬間もある。
- 期待: 開いてすぐ始められる。集中を妨げない。上達が数字で見える。

## 3. デザインが果たす仕事

1. **即座に始められる**: ホームから1タップで訓練開始。迷いゼロ。
2. **集中を妨げない**: 出題中は要素を削り、盤と数字に集中させる。
3. **上達の実感**: 統計で伸びが気持ちよく見える。連続日数などで習慣化を後押し。
4. **音声ファースト対応**: 画面を見ない使い方（③ただ読み上げ）でも成立する。

## 4. 画面一覧

- **ホーム**: 7機能への入口。機能カード or リスト。最近の成績・連続日数をさりげなく。
- **各機能画面**: 「開始 → 出題ループ → 結果サマリ」の共通フロー。中心は 9×9 の盤。
- **統計**: 正答率・平均反応時間・日別推移・連続日数のグラフ。
- **設定**: 話速 / 読みの流派（なな・しち等）/ 盤の向き（先手・後手視点）。
- **支援**: 将来の投げ銭用。今は控えめなプレースホルダ。

各機能画面に必要な要素:
- 9×9 の将棋盤（マスのタップ、任意マスのハイライトに対応）
- 出題表示（符号 or 手順）と音声再生の状態
- 回答UI（①はタップ、②は筋・段の選択、④⑤は手順入力）
- 進捗（何問目/何問中）と、その場のフィードバック（正誤・反応時間）
- 結果サマリ（正答率・平均反応時間・弱点）

## 5. トーンの方向性（主題から引き出す）

避けたいのは「学習アプリのテンプレ」に見えること。将棋という主題の世界から固有の要素を引く。

主題の素材（引き出しに使えるモチーフ）:
- **盤の格子**と余白の「間（ま）」。正方形の秩序。
- **駒の五角形**シルエット。
- 木・和紙・墨の質感、静けさ。対して、反応速度を競う**スポーティさ・計測器っぽさ**。
- 「**見えない盤**」というこのアプリ固有のテーマ — 盤が薄れて記憶で補う、光る一マス、といった視覚表現の余地。

方向性の候補（どれか一つに寄せて、大胆さは一箇所に集中）:
- **A. 静かな鍛錬**: 和の余白・墨・木目を土台に、光る一マスだけが主役。禅的でミニマル。上達の数字は静かに効かせる。
- **B. 計測器・道場ダッシュボード**: 反応時間ミリ秒・正答率を主役にした、精密機器のような硬質な情報デザイン。等幅数字、目盛り、格子。
- **C. 見えない盤**: 盤をあえて希薄に描き、記憶で補う体験そのものを画面化する。ハイライトや残像の演出が signature。

> 注: AI生成のデザインは「クリーム地 + セリフ見出し + テラコッタ差し色」「黒地 + 蛍光アクセント」「新聞レイアウト」に寄りがち。これらはこのブリーフの既定解にしない。将棋という主題から選ぶこと。

## 6. カラー / タイポの叩き台（差し替え可）

- 数字（反応時間・正答率・座標）は**等幅フォント**で。計測器らしさと視認性の両立。
- 盤・駒は主題の核なので、記号や色の選択に一貫性を持たせる。
- ダークモード想定（スキマ時間・夜間利用が多い）。

## 7. 制約・前提

- スマホ縦持ち・片手操作が主。タップ標的は十分大きく。
- 出題中は認知負荷を最小化（装飾を出さない）。
- 実装は React + Tailwind の PWA。凝った表現もWebで再現できる範囲に。
- アクセシビリティ: キーボードフォーカス可視、モーション低減の尊重、コントラスト確保。

## 8. Claude Design に渡すときの依頼文（例）

> 将棋の「脳内盤」を鍛えるトレーニングアプリのUIをデザインしてください。遊ぶアプリではなく、上達のために毎日短時間まわす計測器のような道具です。スマホ縦持ち・ダークモード前提。まずホーム画面と、代表的な訓練画面（9×9盤の任意の一マスが光り、そのマスを答える／音声で言われた座標をタップする）と、統計画面の3つ。方向性は「◯◯（A/B/Cから選択）」で。将棋の盤の格子・駒の五角形・墨や木の質感といった主題の素材を活かし、テンプレ的な学習アプリに見えないようにしてください。
